# Challenge source and requirements

Challenge post: https://dev.to/challenges/sanity-2026-09-16

## Timeline
- Start: September 18, 2026
- Submission deadline: October 4, 2026, 11:59 PM PDT
- Winners announced: October 22, 2026

## Prizes
$2,500 total, split across five winners. Sub-split between Path One and Path Two is not stated on the challenge page.

## Eligibility
- Must be 18+
- Teams up to four people allowed
- One submission per team per path (no duplicate entries within a path)
- Can submit to both Path One and Path Two, but each needs its own separate post

## Path Two requirements (this project)
Prompt an AI-native IDE to build a working app with a Next.js or Astro frontend and a Sanity backend. Bonus points for using App SDK or Workflows features.

Submission must:
- Publish a post on DEV using the provided template, tagged `#sanitychallenge`
- Include the Sanity project ID or public dataset URL
- Provide testing credentials if the app requires login
- Optionally embed agent session transcripts

Judging emphasizes build-process documentation, app functionality, and schema thoughtfulness — this is why Incident War Room uses Workflows for real approval gating and App SDK for real cross-document analytics, not just as checkbox features.
